# GameZone Rental PS

GameZone Rental PS adalah program sederhana yang dibuat menggunakan bahasa pemrograman Java. Program ini digunakan untuk menghitung biaya penyewaan PlayStation 4 dan PlayStation 5 berdasarkan lama waktu bermain pelanggan.

## Deskripsi

Program ini dibuat untuk mempermudah perhitungan biaya sewa PlayStation. Pengguna bisa memasukkan nama pelanggan, memilih jenis konsol, dan menentukan berapa jam pelanggan akan bermain. Setelah itu, program akan menghitung biaya sewa dan menampilkan total pembayaran.

Selain itu, tersedia juga pilihan untuk menambahkan minuman dan melakukan transaksi baru tanpa harus menjalankan ulang program dari awal.

## Fitur Program

- Memasukkan nama pelanggan.
- Memilih PlayStation 4 atau PlayStation 5.
- Memasukkan lama waktu bermain.
- Menghitung biaya sewa berdasarkan durasi bermain.
- Memberikan diskon sesuai ketentuan program.
- Menambahkan biaya minuman.
- Menampilkan struk pembayaran.
- Melakukan transaksi baru.

## Alat yang Digunakan

- Bahasa pemrograman Java.
- Apache NetBeans sebagai tempat membuat dan menjalankan program.

## Cara Menjalankan Program

1. Pastikan Java dan Apache NetBeans sudah terpasang di komputer.
2. Unduh proyek ini dari GitHub.
3. Buka proyek GameZone Rental PS di Apache NetBeans.
4. Jalankan program melalui NetBeans.
5. Masukkan data pelanggan sesuai petunjuk yang muncul di layar.

## Contoh Perhitungan

Misalnya, pelanggan menyewa PlayStation 4 selama 5 jam dan menambahkan minuman.

- Biaya sewa: 5 × Rp8.000 = Rp40.000
- Diskon 10%: Rp4.000
- Biaya minuman: Rp5.000
- Total pembayaran: Rp41.000
